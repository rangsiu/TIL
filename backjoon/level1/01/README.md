8주차 수업
모두 상수였다.
포인터 변수는 번지를 저장하는데 쓰이는 변수.
``` 포인터는 배열에 접근하기 위한 거```

바뀐 값을 저장하고 이어가기 위해서 배열로 표현된 데이터를 처리하는 건 포인터 변수가 한다.

포인터 변수가 저장하고 있던 값을 바꾸기== 가리키는 메모리의 위치를 변경하는 것.

포인터 변수가 저장하는 주소는 바이트의 주소.
덩어리는 배열 선언에서 내가 임의로 정한 거였다.
        ```a[10][100]-> b[1000]```

메모리가 int/short/float/double..이냐에 따라서 데이터 단위가 달라질 수 있다.
character로 선언해놓고, %d로 입력하게 할 수도 있고,(-> 이거 이해가 안되서 중간고사 실패한 거임.)
